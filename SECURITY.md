# Security Policy

## Supported Versions

We release security patches for active versions of Sentiro.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Sentiro security and engineering team takes security vulnerabilities seriously.

If you believe you have discovered a vulnerability in Sentiro (e.g., authentication bypass, privilege escalation, SSRF via synthetic probes, or SQL injection):

1. **Do NOT open a public GitHub issue.**
2. Send an encrypted or direct email to **`security@sentiro.xyz`** with:
   - Description of the vulnerability and impact
   - Step-by-step reproduction instructions or proof-of-concept (PoC)
   - Proposed mitigation (if any)
3. You will receive an initial response within **24 hours**.
4. We will coordinate a disclosure timeline and credit you in the release notes once patched.
